Academic planning, course registration with prerequisite and clash checks, timetables, digital student ID, and bilingual AI helpdesk (**Jervis**) for Pundra University.

## 🚀 Features

- **Jervis AI Helpdesk**: Instant answers about academic policies, faculty office hours, campus facilities, and exams.
- **Smart Course Registration**: Dynamic prerequisite verification, credit-limit enforcement, and schedule clash detection.
- **Digital Student ID**: Official PUB crest and verifiable digital identity card.
- **Department Timetable & Exam Schedules**: Live updates tailored for PUB CSE students and faculty.
- **Modern Tech Stack**: React 19, TypeScript, TanStack Start & Router, Tailwind CSS, Radix UI.

## 🛠️ Getting Started

```bash
# Install dependencies
bun install   # or npm install

# Start development server
bun dev       # or npm run dev
```
